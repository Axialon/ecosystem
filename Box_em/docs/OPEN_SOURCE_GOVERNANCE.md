# Open Source Governance & Program Office (OSPO) Guide

## 1. Project Governance Philosophy & Legal Entity

**Blackboxes • Box'em** is an open-source engineering initiative designed and developed by **Club V Crew**. Box'em is governed under a transparent, meritocratic open-source model. We believe in providing zero-barrier access to spatial reciprocal constraint tools while maintaining rigorous mathematical precision and security.

---

## 2. Roles & Responsibilities

* **Core Maintainers**: Lead architects responsible for mathematical validity, security, and release signing.
* **Domain Specialists**: Professional contributors curating the 225+ industry profession benchmarks and deliverable milestones.
* **Community Contributors**: Developers submitting bug fixes, UI enhancements, 3D glTF models, and translations.
* **Open Source Backers**: Sponsors funding compute, domain infrastructure, and edge serverless deployment.

---

## 3. Release Lifecycle & Semantic Versioning

Box'em follows strict [Semantic Versioning (SemVer 2.0.0)](https://semver.org/):
* **MAJOR (x.0.0)**: Incompatible schema changes to `.boxem.json` or constraint solver equations.
* **MINOR (1.x.0)**: Backwards-compatible new features (e.g. additional profession packs, new WebGL shaders, AI copilot abilities).
* **PATCH (1.0.x)**: Backwards-compatible bug fixes, UI polish, layout refinements, and test improvements.
