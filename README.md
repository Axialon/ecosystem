## ⚡ Quickstart

### Option 1: Standalone Offline (Zero-Build)
Open the master launcher [`index.html`](index.html) directly in any browser to launch and test all engines side-by-side.

### Option 2: Unified Verification & Test Suite
```bash
# Run tests across all 5 new engines
npm run test:orbitem
npm run test:pulseem
npm run test:capem
npm run test:synthem
npm run test:balancem
```
